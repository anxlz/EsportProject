# Saudi Riyal sign font (U+20C1)

Saudi Riyal Font © Emran Alhaddad – Used under SIL Open Font License 1.1 (see `OFL.txt`).

- Source: npm `@emran-alhaddad/saudi-riyal-font@1.1.0`
  (https://github.com/emran-alhaddad/Saudi-Riyal-Font), files `fonts/regular/saudi_riyal.woff2`
  and `fonts/bold/saudi_riyal.woff2`, copied unmodified and renamed.
- SHA-256: regular `c15a031a5a2fdee1d92da7b8d32554463c2136331283a469eaf706beb761499d`,
  bold `cf3b4adaa1a456e4a416ee999a16d9240f3c7babf082c30cd540dbb84f8a337f`.
- Why: IBM Plex Sans and IBM Plex Sans Arabic (the platform's fonts) have no glyph for
  U+20C1 SAUDI RIYAL SIGN (Unicode 17.0). This font is loaded only for that one code point
  (`unicode-range: U+20C1`), so every other character still uses IBM Plex.
- Embedding: OS/2 fsType 0 (installable), so it may be embedded in PDFs.
